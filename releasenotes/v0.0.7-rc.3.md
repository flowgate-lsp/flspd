# flspd v0.0.7-rc.3 (release candidate)

- Keeps both edits when the dashboard saves settings for two nodes at the same time: before, `nodes.yaml` kept only one of them while memory held both, so the other was reverted at the next restart. Saves are now serialized, and each one writes its own temporary file.
- Stops the Settings page waiting forever when the node list fails to load or the fleet has no node: it shows the error with a retry. Against a backend older than rc.2 (no `list_nodes`), Settings edits that backend's only node, as before.
- Never shows or saves one node's settings or announcement status while another node is selected. Switching nodes clears both forms and the status card, an answer that arrives for the previously selected node is dropped, and Save waits until the selected node's settings have loaded.
- Fixes the dev stack's local relay on checkouts set up before rc.2: only `data/relay` is mounted, and `just setup backend` and `just docker up` write `data/relay/relay.yaml` when it is missing, replacing the empty directory an earlier `docker compose up` may have left in its place.
