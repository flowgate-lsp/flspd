# flspd v0.0.7-rc.5 (release candidate)

LSPS transport hardening and dependency maintenance.

- Rate-limits every LSPS read method, not only the mutating ones: a per-peer limiter now runs before any node lookup or fee-quote signing, and the number of LSPS custom-message handlers running at once is bounded, so a peer sending a burst of reads such as `lsps2.get_info` can no longer drive unbounded signing work or goroutines. (#38)
- Hardens LSPS5 webhook registration and delivery, and adds the `LSPS5_ALLOW_LOOPBACK_WEBHOOKS` setting (default off) to allow loopback webhook URLs in development only. (#35)
- Updates the embedded Lightning node (flnd) to 0.2.5. (#36)
