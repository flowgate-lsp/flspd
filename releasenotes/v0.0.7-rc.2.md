# flspd v0.0.7-rc.2 (release candidate)

- Checks the dashboard admin key before reading a request body, caps bodies at 1 MiB, and bounds the dashboard listener's header, read, write and idle times. A token now enters the replay cache only after every check passed, and the `auth` query parameter is accepted only on the WebSocket upgrade.
- Stops routing the dashboard through traefik in `docker-compose.prod.yml`: it listens on the host's 127.0.0.1 only, and `docker-compose.prod.dashboard.yml` exposes it on purpose over a TLS entrypoint. Postgres now requires `POSTGRES_PASSWORD` (scram-sha-256) instead of trusting every container on the network; an existing data directory needs its `pg_hba.conf` `trust` lines changed (see README).
- Stops logging the payment secret on the legacy RegisterPayment path, in its store log line and error, and in decrypt-then-unmarshal failures.
- Gives each node of a fleet its own LSPS answers and sales: its protocol list, JIT switch, LSPS1 options and fee menu come from its own config, so each node's announcement matches what that node answers. A token or fee quote of another node is no longer accepted on this node.
- Never signs an announcement more than 10 minutes ahead of its clock, below the 15-minute future bound clients apply. A re-publish after the clock steps back within that lead is still newer; beyond it, the event is signed at the clock.
- Turns NIP-LSP announcing on in the dev sample (`deploy/nodes.dev.sample.yaml`), published to a local relay the dev compose now runs (`ws://flspd-dev-relay:5500`, also on `flowgate-integration`) unless `.env` sets other relays.
- Lets the dashboard pick the node its settings and announcement actions (pause, resume, unlist, recheck) apply to: `get_config`, `update_config` and the announcement methods take a `node` id, required when the fleet has more than one node, and the Settings page shows a node selector. `list_nodes` lists the fleet; an unknown node is refused.
- Requires nmilat v0.5.0-rc.45, which enforces the 15-minute future bound on an announcement's `created_at` (NIP-LSP step 4); the K-LSP vector for that bound now runs instead of being skipped.
